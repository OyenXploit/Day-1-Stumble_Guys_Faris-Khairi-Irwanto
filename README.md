### Rangkuman Materi
Materi hari ini membahas tentang "Building with AI, Managing Change with GitHub". Beberapa poin utamanya adalah:   
Prompt Engineering: Cara memberikan instruksi atau konteks kepada model AI untuk mendapatkan hasil yang relevan. Struktur prompt yang baik harus memiliki Role (peran), Task (tugas utama), Context (batasan atau latar belakang), dan Format (bentuk output).   

Git vs GitHub: Git adalah version control system yang melacak perubahan file secara lokal, sedangkan GitHub adalah platform web untuk menyimpan repository secara online agar mudah berkolaborasi.   

Git Workflow: Alur kerja perubahan file terdiri dari tiga tahap: Working Directory (tempat file dikerjakan), Staging Area (menandai perubahan dengan git add), dan Repository (menyimpan permanen dengan git commit).   

Praktek Dasar Git: Menggunakan command esensial seperti git init, git clone, git add ., git commit -m, dan git push untuk mengelola proyek sederhana seperti "Student Task Planner".   

Poin Penting / Pengetahuan BaruMendapatkan pemahaman yang lebih jelas tentang perbedaan mendasar antara Git (lokal) dan GitHub (cloud/online).
Mengetahui pentingnya Context dan Format saat menggunakan AI; memberikan instruksi yang spesifik akan mengurangi bias dan menghasilkan output kode atau teks yang langsung bisa digunakan.
